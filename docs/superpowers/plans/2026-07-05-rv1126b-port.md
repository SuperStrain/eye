# RV1126B Platform Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add RV1126B Rockit support to `eye` while preserving Hi3516CV610 builds and behavior from the same source tree.

**Architecture:** Keep platform-specific media code under `modules/platform/<platform>`. Add a platform factory interface so `app/main.cpp` depends on `IVideoPipeline` and `IStreamProvider` instead of HiSilicon headers. Select the active platform through `TARGET_PLATFORM` and platform-specific CMake/toolchain files.

**Tech Stack:** C++11, CMake, HiSilicon MPP, Rockchip Rockit MPI, Buildroot SDK, zlog, pthread, live555 RTSP.

## Global Constraints

- Target runtime is embedded Linux; ARM binaries must not be executed on the PC host.
- Hi3516CV610 must remain compatible with the existing `arm-v01c02-linux-musleabi-` toolchain and existing platform behavior.
- RV1126B must use `/opt/aarch64-buildroot-linux-gnu_sdk-buildroot` with compiler prefix `aarch64-buildroot-linux-gnu-` and sysroot `${SDK_ROOT}/aarch64-buildroot-linux-gnu/sysroot`.
- RV1126B Rockit headers and `librockit.so` are installed in the `/opt` sysroot; do not depend on SDK source-tree Rockit paths for normal builds.
- Default install prefix remains `$HOME/eyeOut` for SDK `07_atk_dlrv1126b_automipi_eye_defconfig` app partition packaging.
- Keep changes minimal and platform-scoped; do not refactor unrelated modules.
- Do not commit unless the user explicitly asks for commits.

```cpp
int RvVideoPipeline::init_sys() {
    int ret = RK_MPI_SYS_Init();
    if (ret != RK_SUCCESS) {
        LOGGER_ERROR(HIMPP, "RK_MPI_SYS_Init failed: %#x", ret);
        return ret;

int RvVideoPipeline::init_vi_dev() {
    VI_DEV_ATTR_S dev_attr;
    VI_DEV_BIND_PIPE_S bind_pipe;
    std::memset(&dev_attr, 0, sizeof(dev_attr));
    std::memset(&bind_pipe, 0, sizeof(bind_pipe));

    int ret = RK_MPI_VI_GetDevAttr(kPipeId, &dev_attr);
    if (ret == RK_ERR_VI_NOT_CONFIG) {
        ret = RK_MPI_VI_SetDevAttr(kPipeId, &dev_attr);
        if (ret != RK_SUCCESS) {
            LOGGER_ERROR(HIMPP, "RK_MPI_VI_SetDevAttr failed: %#x", ret);
            return ret;
        }
    }

    ret = RK_MPI_VI_GetDevIsEnable(kPipeId);
    if (ret != RK_SUCCESS) {
        ret = RK_MPI_VI_EnableDev(kPipeId);
        if (ret != RK_SUCCESS) {
            LOGGER_ERROR(HIMPP, "RK_MPI_VI_EnableDev failed: %#x", ret);
            return ret;
        }
        bind_pipe.u32Num = 1;
        bind_pipe.PipeId[0] = kPipeId;
        ret = RK_MPI_VI_SetDevBindPipe(kPipeId, &bind_pipe);
        if (ret != RK_SUCCESS) {
            LOGGER_ERROR(HIMPP, "RK_MPI_VI_SetDevBindPipe failed: %#x", ret);
            return ret;
        }
    }
    return 0;
}
```

```cpp
int RvStreamFetcher::fetchFrame(VencChannel chn, FrameData& frame) {
    int chn_val = static_cast<int>(chn);
    VENC_STREAM_S stream;
    VENC_PACK_S pack;
    std::memset(&stream, 0, sizeof(stream));
    std::memset(&pack, 0, sizeof(pack));
    stream.pstPack = &pack;

    int ret = RK_MPI_VENC_GetStream(chn_val, &stream, 1000);
    if (ret != RK_SUCCESS) {
        return -1;
    }

    void* data = RK_MPI_MB_Handle2VirAddr(pack.pMbBlk);
    if (data == nullptr || pack.u32Len == 0) {
        RK_MPI_VENC_ReleaseStream(chn_val, &stream);
        return -1;
    }

    frame.pack_count = 1;
    frame.seq = 0;
    frame.packs[0].data = static_cast<const uint8_t*>(data);
    frame.packs[0].len = pack.u32Len;
    frame.packs[0].nalu_type = map_nalu_type(codec_type_, pack);

    auto stream_frame = std::make_shared<StreamFrame>(channel_, stream_type_, codec_type_, frame);
    ret = RK_MPI_VENC_ReleaseStream(chn_val, &stream);
    if (ret != RK_SUCCESS) {
        LOGGER_ERROR(STREAM, "RV1126B ch%d RK_MPI_VENC_ReleaseStream failed: %#x", chn_val, ret);
    }
    distributor_.push(stream_frame);
    return 0;
}
```
